## Implemented
Named role-gated candidate review, explicit source version, rationale-backed accept/reject/clarify,
withdrawal, versioned decision snapshots, optimistic concurrency, historical read-only change revisions,
and explicit copy-as-candidate. The product interface exposes these workflows without implying that a
requirement's acceptance proves software correctness. No verifier run or disposition is fabricated.
Shared database sessions and fail-closed hosted configuration replace unsafe baseline defaults.
Additive migration retains existing registry rows and records legacy authorship as unknown.
